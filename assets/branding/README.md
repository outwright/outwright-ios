# Outwright icon concepts

The terracotta icon is the preferred direction, selected by Jörgen on 2026-11-07. The blue icon is retained as an alternative. The app icon is `App/AppIcon.icon`, an Icon Composer document with layers for iOS 26 (background gradient, ribbon, envelope, flap), redrawn after the terracotta concept. Its source is `outwright-icon.vectorcraft`; edit it there, export SVG and split the layers into `App/AppIcon.icon/Assets/`.

Generated with the built-in image generation tool.

Prompts: an original email app icon with a prominent ivory envelope and a subtle folded ribbon behind it; no text or vendor assets. The terracotta variant preserves the composition and replaces blue and cyan with warm coral, terracotta and peach.

## App color direction

Use terracotta as the accent for the selected tab, primary buttons, selection highlights and small details. Keep backgrounds neutral so mail remains the focus: warm off-white in light mode and charcoal in dark mode. Keep gradients and dimensional shading in the icon. The app and icon should feel like the same product without making the whole interface orange.
